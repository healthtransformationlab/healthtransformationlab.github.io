How scoring works

What a score means on synthetic records, and how real records would be scored.

On synthetic records: agreement with an answer key, not accuracy

PerioBench scores rules and AI that find gum disease in dental records. Each reads a record and answers with a status, from healthy to periodontitis stage 4, under the 2017 classification.

On synthetic records, the generator first invents each patient's gum measurements. It then applies the project's own 2017 rules to those measurements to get the true status, and writes the chart, note, codes and X-ray reading from it, with mistakes added on purpose. That true status goes in an answer key no method sees.

That answer key is right because we defined it, not because anyone checked it. So a synthetic score shows how well a method recovers our rules through the noise we added. It is agreement with the synthetic answer key, not accuracy on real patients.

It is still useful: it shows the code works end to end, compares methods under the same known conditions, and shows how much worse each gets as records get messier. Two things make the gap to real records bigger, and the results now show both:

  • Some methods use the same rules that made the answer key, so they start with an advantage real records won't give them. The leaderboard marks them with †.
  • Some records can't be staged. Staging needs gum or bone measurements. 13 of the 240 test charts have no gum chart and no X-ray, and their notes state exactly the true status, so a method that copies the note looks right for free. Scores are now reported separately for records that can and can't be staged.

On real records: compared with specialists

On real records nobody knows the true status, and the recorded diagnosis code isn't it: it is often missing or doesn't fit the chart. So PerioBench uses the acceptance test OHDSI uses (Schuemie, Ostropolets et al., npj Digital Medicine, 2025):

  1. Several reviewers stage the same records independently, seeing the chart, X-rays, notes and codes.
  2. Their agreement with each other is the bar. Reviewers never agree perfectly.
  3. A method passes if it agrees with the reviewers at least as much as they agree with each other. It isn't compared with their combined answer, which each reviewer helped make.

When a record holds too little to stage, a reviewer can say "can't determine". Those records are reported apart, not guessed.

The review tool is built, but no real review has happened. Results from simulated reviewers test the code only and are labelled simulated.

A low-cost reference

  1. A chart-derived reference: on real records with a full gum chart and an X-ray, apply the 2017 rules to those measurements, and score how well the rest of the record (note, codes, forms) agrees.
  2. A small review by people already involved: for example 50 records, two reviewers each. That is enough to see how well they agree and where methods fail, though not enough to prove a method passes.
  3. Report the gap between the synthetic score and the real one. Its size is itself a finding about data quality.
